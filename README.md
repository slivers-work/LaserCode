# LaserCode
Laser marking code location detection + laser marking code information recognition（镭刻码位置识别+镭刻码信息识别）
镭刻码位置识别通过yolov26，信息识别通过parseq
## 脚本说明
detection.py是用来找位置和识别
ui_app.py是界面
best.pt是yolo训练模型的权重文件
---------------------------------
压缩包是模型的环境文件，还有一个torch_cache文件里有一个模型权重文件在本机电脑Pycharm的0422项目中
